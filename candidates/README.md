# Exercise candidates

AI-generated exercise bundles will land here before publication.

A candidate is **not** part of the learner's exercise library until it passes
`tools/exercise_validator.py` and is published with `tools/publish_candidate.py`.

The bundle contains:
- public exercise metadata/starter
- hidden reference solution
- hidden tests
- optional support/analysis-support files

The learner-facing server blocks direct access to `/candidates/`.
